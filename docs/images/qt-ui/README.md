# Qt 界面截图目录

README 和文档中预留了以下截图位置：

- `main-window.png`：Qt 主界面整体效果。
- `detection-preview.png`：Detection Preview 模式下的人脸检测效果。
- `history-query.png`：History 页签，包含 Face 列和手动绑定区域。
- `faces-library.png`：Faces 页签，包含人员库、参考图输入和 Recognition 状态。
- `recognition-ready.png`：识别可用性诊断显示 `Ready` 时的状态。

建议截图使用 PNG 格式，宽度控制在 1200 到 1600 像素之间，方便 GitHub README 展示。

截图时优先展示真实人脸检测 / 识别流程，不再使用工业缺陷检测样例。
